# Archive: Presentation Revision Ledger

This branch collects the dated revision records and one representative pre-final source backup used while refining the Flow5 presentation. It is a reference branch; it is not part of the deployed Pages build.

## Revision sequence

- **first-rebuild** — initial structured rebuild from the earlier component workbench, with the first evidence and validation contract.
- **before-header-cleanup** — the workbench still exposed component usage and source-scope labels in the page header.
- **before-eyebrow-removal** — plain-English subtitles were still visible; the final visual direction later removed the eyebrow treatment.
- **before-contribution-evidence** — contribution evidence was still being assembled before the balanced nine-member map and detailed XingTang evidence record.
- **quality-pass-before-expansion** — representative `ModelEvidenceGallery.vue` and its source archive before empty model-output slots were replaced by populated real-image diagnostics.

## Why the changes happened

The sequence records a move from component catalogue presentation toward a report-led evidence deck. Header metadata was reduced to audience-facing titles, subtitle labels were removed, unavailable model exports stayed explicitly unavailable, and the evidence page was expanded with real FiveK diagnostics and source-bounded contribution records. The final delivery also aligned browser checks with the replacement contribution-card component.

## Included material

Each dated directory retains the available project state, publication state, role manifest and verification record. The quality-pass directory also retains the representative source archive and the earlier model-output gallery component. Large generated transaction bundles remain outside the active application tree; their role records and hashes are preserved in the included metadata.

## Evidence boundary

The records describe historical attempts and validation events. They do not add new model results or establish that an archived visualisation was a trained Flow5 export. For the current 52-page presentation and hosted QA result, use `main`.
